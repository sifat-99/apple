# Apple Gadgets E-Commerce

![Apple Gadgets Banner](./images/assets/logo.png)

This project is a fully responsive, front-end clone of the Apple Gadgets e-commerce website. It features interactive carousels, dynamic category switching, and a modern, premium user interface designed to provide an excellent shopping experience across all devices.

## Challenges

The main challenge of this project was perfectly recreating a complex e-commerce user interface using **vanilla HTML, CSS, and JavaScript** without relying on frameworks like Tailwind CSS or React. Managing the state for multiple independent carousels (Hero carousel, Deals carousel, etc.) and ensuring pixel-perfect responsiveness across mobile, tablet, and desktop screens required careful planning of CSS Grid and Flexbox layouts.

## Key Features

1. **Interactive Carousels:** Custom-built auto-scrolling hero carousels and product slider carousels with Next/Prev button controls and dot navigation.
2. **Dynamic Category Tabs:** Users can switch between product categories (e.g., Best Selling, Top Selling) dynamically, and the UI updates the respective carousels without page reloads.
3. **Fully Responsive Design:** The layout seamlessly adapts to Desktop, Tablet, and Mobile devices using CSS Media Queries. Includes a sticky mobile bottom navigation bar.
4. **Modern UI Components:** Features hover effects, clean typography, badge overlays, and organized grid layouts for product cards and footer sections.
5. **No External Frameworks:** Built entirely from scratch using vanilla web technologies for maximum performance and control.

## Used Technologies

1. **HTML5**: Semantic structure and layout.
2. **CSS3**: Styling, Flexbox, CSS Grid, animations, and media queries.
3. **JavaScript (ES6)**: DOM manipulation, event handling, and carousel logic.
4. **Font Awesome**: Used for scalable vector icons.

## Used Utility

1. **Primary Color:** `#ff5c00` (Orange)
2. **Background Color:** `#000000` (Footer/Navbar)
3. **Primary Font:** `Inter`, sans-serif
4. **Secondary Font:** System UI fonts

## Project Setup

Clone the repository and run it locally:

```bash
  # Clone the repository
  git clone https://github.com/your-username/applegadgets.git

  # Navigate to the project directory
  cd applegadgets

  # Open index.html in your browser
  # Or use a live server extension in VS Code
```
